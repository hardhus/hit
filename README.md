# hit

A keyboard-driven terminal UI for GitHub — open it and see what needs your attention.

> **Status:** early development (v0.0.0). Nothing usable yet.

## Goals

- **Focus first:** the start screen shows what needs you — review requests, your PRs with failing CI or requested changes, mentions, assigned issues.
- **Keyboard only, low friction:** the 90% of daily GitHub work, done comfortably from the terminal.
- **Self-contained:** talks to the API directly; no `gh` required (`hit auth login`).
- **Forge-agnostic core:** GitHub first; GitLab, GitHub Enterprise and Gitea/Forgejo are planned behind the same abstraction.
